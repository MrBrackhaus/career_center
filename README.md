# JobTracker

JobTracker ist eine datenschutzfreundliche Open-Source-App (Flutter), die Arbeitssuchenden dabei hilft, ihre Bewerbungen zu organisieren, Nachweise für das Jobcenter zu verwalten und ihre Chancen auf dem Arbeitsmarkt durch dynamische Berufsprofile und intelligente Vorlagen zu verbessern. 

Alle persönlichen Daten werden ausschließlich lokal auf dem Gerät (via SQLite/Drift) gespeichert, um maximale Privatsphäre und Datensouveränität zu gewährleisten.
